## Privacy Policy

### Data Collection

The plugin does not collect, store, or transmit any personal data. It does not require credentials or API keys.

The image files you pass to the tool are downloaded inside the Dify plugin runtime, merged locally, and returned as a single image. No copy of the input or output images is kept by the plugin after the tool invocation finishes.

### Data Usage

The images are used solely to produce the merged image requested by the tool invocation. No data is shared with any third-party service.

### Data Retention

The plugin keeps no data beyond the lifetime of a tool invocation. Images returned by the tool are stored by your own Dify deployment according to its file retention settings.

### Contact

For privacy-related questions, please open an issue in the plugin repository.
